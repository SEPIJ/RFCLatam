# Ready Fractional Chief — Landing Page

Sitio estático de una sola página (`index.html`). Logos y favicons están
incrustados como base64 dentro del propio HTML.

## Desplegar en Vercel
1. Entra a https://vercel.com/new
2. Arrastra esta carpeta (`rfc-landing`) al recuadro de importación
3. Deploy — Vercel la detecta como sitio estático, no requiere build command

## Dominio propio
Settings → Domains → agrega RFCLatam.com y sigue las instrucciones de DNS.
